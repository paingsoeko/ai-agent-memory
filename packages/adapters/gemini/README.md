# @ai-agent-memory/adapter-gemini

Gemini CLI: settings.json MCP entry, GEMINI.md bootstrap text, /memory custom command.

Adapters only provide bootstrap instructions, hooks, configuration snippets and context formatting. All storage lives in `@ai-agent-memory/core`; the memory database is shared across every agent.

Docs: https://github.com/paingsoeko/ai-agent-memory/blob/main/docs/integrations/
