# @local-ai-agent-memory/adapter-opencode

OpenCode: opencode.json MCP entry, AGENTS.md bootstrap text, session.idle ingestion plugin.

Adapters only provide bootstrap instructions, hooks, configuration snippets and context formatting. All storage lives in `@local-ai-agent-memory/core`; the memory database is shared across every agent.

Docs: https://github.com/paingsoeko/ai-agent-memory/blob/main/docs/integrations/
