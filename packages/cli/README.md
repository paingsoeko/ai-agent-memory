# @ai-memory/cli

```bash
npm install -g @ai-memory/cli
aam init
aam remember "I prefer PostgreSQL for backend projects."
aam recall "database preference" --json
aam mcp   # how to connect Claude Code, Codex, Gemini CLI, OpenCode
```

Commands: init, status, remember, recall, search, list, inspect, update, forget, promote/demote, project, scene, events, ingest, consolidate, embed, export, import, privacy, config, mcp. `--json` everywhere. Docs: https://github.com/ai-memory/ai-memory/blob/main/docs/cli.md
